# Bundesbank bank code file

`blz-aktuell.txt` is the Deutsche Bundesbank's bank code file (Bankleitzahlendatei), shipped byte for byte as
published. It is not covered by Finglass's MIT licence.

- Quelle: Deutsche Bundesbank
- Source: https://www.bundesbank.de/de/aufgaben/unbarer-zahlungsverkehr/serviceangebot/bankleitzahlen/download-bankleitzahlen-602592
- Valid: 07.09.2026 to 06.12.2026
- SHA-256: 5872bf19298f55cc0594d22656b72e0f8ff277faedbf5b18f9b7f3bcae4c606b
- Format: Merkblatt Bankleitzahlendatei, Anhang 1 (fixed width, 168 characters, ISO-8859-1, CRLF)

The Bundesbank's terms of use (section 4.1) allow storing, passing on and copying its information for personal or
business use, unaltered and with the credit "Quelle: Deutsche Bundesbank". To update, replace the file with the
current download unchanged and update the period and checksum above.
