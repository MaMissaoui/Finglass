A small maintenance release. No change to what Finglass does. Still read-only and local-first: nothing in Finglass can
move money.

**Alpha software.** Keep a backup of your data. This build is for macOS 13 or later only.

## Fixed

- **Documents, first open:** the check for text recognition no longer lets the app look idle before its follow-up
  reload has started. This only showed up as a hanging test on slow Windows build machines, but the order is now
  right everywhere.

## Security

- No known vulnerability affects this build: `govulncheck` checked the source and the app binary, and `npm audit`
  reports none.
- The test and build tools were updated (Playwright 1.65, setup-go 7.1).
