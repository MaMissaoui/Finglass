A fix for the account panel, from your feedback on 0.3.2. Still a read-only, local-first app: nothing in Finglass can
move money.

**Alpha software.** Keep a backup of your data and of FinDesk's. This build is for macOS 11 or later only.

## Fixed

- **Transactions → account panel:** with every group collapsed, "All accounts" (and the group rows) could stretch over
  the panel's empty space. Rows now keep their own height and the free space stays below the list. The settings
  section list and an account's recent bookings got the same fix.

## Install

Double-click `install-mac.command` from a checkout to download and install this release, or:

1. Download `Finglass_0.3.3_aarch64.dmg` below. `SHA256SUMS.txt` holds its checksum.
2. Open the DMG and drag Finglass into Applications, replacing 0.3.2. Your data stays where it is.
3. The app is ad-hoc signed, not notarized, so macOS blocks the first launch:
   1. Open Finglass once, then close the warning.
   2. Go to **System Settings → Privacy & Security** and choose **Open Anyway**.

OCR for images and scanned PDFs uses Tesseract and Poppler:

```sh
brew install tesseract tesseract-lang poppler
```
