The first Finglass built in Go: the same app as 0.3.4, rewritten with a Go core and a Wails + Svelte window, plus a
read-only **Test connection** for your banks over FinTS. Still a read-only, local-first app: nothing in Finglass can
move money.

**Alpha software.** Keep a backup of your data and of FinDesk's. This build is for macOS 13 or later only.

## New

- **Test connection:** on the Accounts page, each bank's menu has a read-only check that logs in over FinTS 3.0 with
  PIN/TAN, reads the account list, balances and statements, and imports nothing. It asks only for your PIN and TAN.
  - Finglass only ever asks your bank for account lists, balances and statements (MT940 or camt). It has no code that
    could send a transfer or any other order.
  - The panel shows the bank's own warnings and errors. They can contain account details, so they are shown there
    only and never saved.
  - "Save redacted trace…" writes a structural log of the exchange, for troubleshooting. Your PIN, TAN, ids, amounts
    and bookings are removed, and IBANs and bank texts are masked to their last 4 characters.
- **Online sync** is built in but still switched off. It is switched on in a 0.4.x update once every tested bank
  passes Test connection.

## Changed

- **Rewritten in Go** with a new window (Wails + Svelte). Pages, reports, documents, backup and restore, profiles and
  the FinDesk import work as in 0.3.4.
- Finglass still opens 0.3.4 data folders and restores 0.3.4 backups.

## Start fresh from FinDesk

To start over with your FinDesk data instead of your 0.3.4 data:

1. Install this release (below) and quit Finglass.
2. Rename your data folder `~/.finglass`, for example to `~/.finglass-0.3.4`. Keep it; don't delete it.
3. Start Finglass. On an empty data folder it offers to import your FinDesk profiles. FinDesk's folder is only read,
   never changed.

## Install

Double-click `install-mac.command` from a checkout to download and install this release, or:

1. Download `Finglass_0.4.0_universal.dmg` below. `SHA256SUMS.txt` holds its checksum.
2. Open the DMG and drag Finglass into Applications, replacing 0.3.4.
3. The app is ad-hoc signed, not notarized, so macOS blocks the first launch:
   1. Open Finglass once, then close the warning.
   2. Go to **System Settings → Privacy & Security** and choose **Open Anyway**.

OCR for images and scanned PDFs uses Tesseract and Poppler:

```sh
brew install tesseract tesseract-lang poppler
```
