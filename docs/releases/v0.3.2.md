A calmer, more consistent look on every screen, and the month's carry-forward for every month. Still a read-only,
local-first app: nothing in Finglass can move money.

**Alpha software.** Keep a backup of your data and of FinDesk's. This build is for macOS 11 or later only.

## What's new

- **One set of text sizes everywhere.** Figures, titles, list rows, secondary lines and labels each have one size and
  weight on every screen. Dialog titles now match the page titles, and small text is never mixed with larger text
  of the same kind.
- **Colour only where it means something.** The accent colour marks only what you can click. Account types, a
  document's linked booking and the profile name are now plain text. The profile and language selectors look the
  same.
- **Dashboard.** Open tasks read like the statement beside them, and "Alle anzeigen" sits in the title row of the
  recent bookings.
- **Accounts.** The bank header is on one scale, and "Konten ohne Bank" lines up with the banks above it.
- **Transactions.** The account list uses one style for every count, and all amounts in lists share one weight.

## Fixed

- **Dashboard → carry-forward:** the "Übertrag" line was hidden whenever one of the available accounts had no
  booking before the month. It now shows for every month, computed back from today's balances of the available
  accounts, so the statement always adds up.

## Install

Double-click `install-mac.command` from a checkout to download and install this release, or:

1. Download `Finglass_0.3.2_aarch64.dmg` below. `SHA256SUMS.txt` holds its checksum.
2. Open the DMG and drag Finglass into Applications, replacing 0.3.1. Your data stays where it is.
3. The app is ad-hoc signed, not notarized, so macOS blocks the first launch:
   1. Open Finglass once, then close the warning.
   2. Go to **System Settings → Privacy & Security** and choose **Open Anyway**.

OCR for images and scanned PDFs uses Tesseract and Poppler:

```sh
brew install tesseract tesseract-lang poppler
```
