Fixes after 0.2.1, found by reviewing every page with a real profile. Still a read-only, local-first app: nothing
in Finglass can move money.

**Alpha software.** Keep a backup of your data and of FinDesk's. This build is for macOS 11 or later only.

## What's new

- **German amounts in the German way.** With German as the app language, amounts read `2.450,37 €`, `-5.000,00 €`
  and `4.000 €` on chart axes, with a space that never breaks the amount across lines. English is unchanged; French
  is unchanged for now. FinDesk shows amounts the same way from its next release.

## Fixed

- **Reports → Recurring:** the columns stay under their headings, also next to a long payee name.
- **Transactions:** the figures above the list ("Umsätze", "Eingang", "Ausgang") no longer run together.
- **Settings:** the section list no longer wraps long German names, so every row has the same height. In
  Categories, "Add default categories" and "Give every category its own colour" moved into a ⋮ menu, so the
  header fits on one line.
- **Account properties:** a balance that didn't change in the period shows one axis label, not the same value twice.
- **Bank logos:** the bundled logo files are now the same as FinDesk's.

## Install

1. Download `Finglass_0.2.2_aarch64.dmg` below. `SHA256SUMS.txt` holds its checksum.
2. Open the DMG and drag Finglass into Applications, replacing 0.2.1. Your data stays where it is.
3. The app is ad-hoc signed, not notarized, so macOS blocks the first launch:
   1. Open Finglass once, then close the warning.
   2. Go to **System Settings → Privacy & Security** and choose **Open Anyway**.

OCR for images and scanned PDFs uses Tesseract and Poppler:

```sh
brew install tesseract tesseract-lang poppler
```
