A fix for the HypoVereinsbank login, and Test connection with your saved PIN. Still read-only and local-first:
nothing in Finglass can move money.

**Alpha software.** Keep a backup of your data. This build is for macOS 13 or later only.

## Fixed

- **Signature header for TAN methods.** Finglass signed every message as a one-step (PIN only) message, even with a
  TAN method such as pushTAN or appTAN. A bank then can't make sense of the TAN request in it; HypoVereinsbank
  answered "Kein eingereichter Auftrag gefunden". Messages with a TAN method are now signed as two-step messages, as
  working clients do. The PIN-only first registration is unchanged.
- The second try after HypoVereinsbank's answer (the new registration with the TAN method) no longer sends an empty
  device id in the security headers.

Both changes touch every bank, so please test **Volksbank first**, then HypoVereinsbank (see below). The new
registration path at HypoVereinsbank could not be compared with a working client yet; if it still fails, the saved
trace tells us why.

## New

- **Test connection uses your saved PIN.** When the bank has a remembered PIN, Test connection uses it instead of
  asking. It still never saves a PIN itself.
- **Remove the saved PIN after the first or the second rejection** (per bank, in the bank's connection settings). A
  clear wrong-PIN answer always removes it at once. A rejected TAN never counts against the PIN.

## Changed

- A sync that fails because of the network keeps the saved PIN.

## Please test

1. **Volksbank:** Accounts → bank menu → **Test connection**. It must still say **GO**. If it doesn't, stop here and
   send the result and the saved trace.
2. **HypoVereinsbank:** Test connection, then send the result text and **Save redacted trace…**. Each attempt
   registers another device at HypoVereinsbank.

## Install

1. Download `Finglass_0.4.3_universal.dmg` below. `SHA256SUMS.txt` holds its checksum.
2. Quit Finglass, open the DMG and drag Finglass into Applications, replacing the older version. Your data stays as it
   is.
3. The app is ad-hoc signed, not notarized: if macOS blocks the first launch, go to **System Settings → Privacy &
   Security** and choose **Open Anyway**.
