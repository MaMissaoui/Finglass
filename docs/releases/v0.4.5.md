A save button for each bank's trace after Sync all, a local bank list for server addresses, and groundwork for
Windows and Linux. Still read-only and local-first: nothing in Finglass can move money.

**Alpha software.** Keep a backup of your data. This build is for macOS 13 or later only.

## New

- **Settings → Load bank list…** Load the FinTS bank list (CSV) you received from the DK. It stays on this computer,
  only the bank code, server address and bank name are kept, and Add bank fills in an empty server address from it.
  Finglass ships no list. Remove it again in Settings.

## Fixed

- **After Sync all, every bank can save its own redacted trace.** Before, only the last bank offered "Save redacted
  trace…", and that file held every bank's dialog.
- The Sync all summary shows one line per bank instead of running them together.

## Removed

- The real-data screenshot tool (`scripts/real-data-shots.sh`). Screenshots are taken by hand when needed.
