An update for testing the HypoVereinsbank login. Still a read-only, local-first app: nothing in Finglass can move
money. Online sync stays switched off in this release.

**Alpha software.** Keep a backup of your data. This build is for macOS 13 or later only.

## New

- **Test connection, second try for HypoVereinsbank:** when a bank rejects the login with 9210 ("Kein eingereichter
  Auftrag gefunden"), Test connection now registers the device once more and asks for the TAN during that
  registration, as other FinTS programs do. What to expect:
  - You may get two approval requests in the HVB app: one for the rejected login and one for the new registration.
    Approve the newest one and type the TAN it shows. Ignore the older one.
  - Each attempt registers another HBCI device at HVB.
  - The result says which path ran ("Registered again with the TAN method") and whether the bank asked for a typed TAN
    or an approval in its app. Please send that line, the bank's messages from the panel, and a saved trace.
- Banks that already work (Volksbank) take the same path as in 0.4.0.

## Changed

- Finglass never repeats a PIN in the same attempt after the bank answers with a security code (93xx or 99xx), so a
  wrong PIN can't count twice.

## Install

1. Download `Finglass_0.4.1_universal.dmg` below. `SHA256SUMS.txt` holds its checksum.
2. Quit Finglass, open the DMG and drag Finglass into Applications, replacing 0.4.0. Your data stays as it is.
3. The app is ad-hoc signed, not notarized: if macOS blocks the first launch, go to **System Settings → Privacy &
   Security** and choose **Open Anyway**.
