Clearer bank status, plain-language test results and a calmer Accounts header. Still read-only and local-first:
nothing in Finglass can move money.

**Alpha software.** Keep a backup of your data. This build is for macOS 13 or later only.

## New

- **Status line per bank** on the Accounts page: one sentence that says whether the bank can sync, why not, and
  what to do next (Sync, Test connection, or Connection settings).
- **Test connection opens with the verdict** — GO, NO-GO or "Not completed" (cancelled or no bank answer) — and a
  next step. Every failure is named in a sentence; the missing FinTS registration (DKB today, code 9078) says there
  is nothing to change in Finglass and to test again in a few days.

## Changed

- **One main currency per figure** in the Accounts header; other currencies sit on a small line below. The header no
  longer overlaps at the narrowest window width in French.
- **"Quit FinDesk first"** shows only while FinDesk is running (or when Finglass can't tell).
- Screen readers now hear the budget bar ("62 % of the budget used; 47 % of the month has passed") and a changed
  number of pending tasks.
- The status colours follow the System theme in dark mode too.

## Fixed

- TAN answers from banks that use the older HKTAN version 5 are read from the right fields.

## Please test

1. Accounts: each bank shows a status line; Volksbank and HypoVereinsbank say they can sync.
2. Test connection on DKB: the result names the missing registration and says to test again later.
3. Settings → Import from FinDesk with FinDesk closed: no "Quit FinDesk first" note; with FinDesk open: the note.

## For developers

- `scripts/real-data-shots.sh <backup> <folder>` screenshots every page from a backup, never from `~/.finglass`.
- Windows and Linux: the Go tests pass there, and private folders get an owner-only DACL on Windows. No Windows or
  Linux builds are published yet.
