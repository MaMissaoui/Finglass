A security maintenance release: the encryption library that protects your database is updated. No change to what
Finglass does. Still read-only and local-first: nothing in Finglass can move money.

**Alpha software.** Keep a backup of your data. This build is for macOS 13 or later only.

## Security

- **SQLCipher 4.20.0 with SQLite 3.54.1** (was SQLCipher 4.15.0 with SQLite 3.53.0). The update brings upstream fixes
  for the crypto code Finglass uses (LibTomCrypt: random-generator reinitialisation and error handling, 4.17.0) and
  two low-risk security fixes (4.19.0). An earlier note said the missed fixes were only in features Finglass does
  not use; the 4.17.0 crypto fixes do apply.
- Your database file format does not change. Existing databases open as before, with the same passphrase; nothing is
  converted.
- The bundled code was checked: it is byte-identical to a build from the official SQLCipher 4.20.0 source.

## Please test

1. Unlock with your passphrase: your data is all there.
2. Enter a wrong passphrase once: you get the usual "wrong passphrase" message, then unlock with the right one.
3. Sync now on Volksbank or HVB still works.
